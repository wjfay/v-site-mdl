기존에 빌드한 개인 포트폴리오 웹사이트에 새로운 Model Portfolio 페이지를 추가해줘.

이번 페이지는 단순히 기존 웹사이트와 연결되는 추가 페이지가 아니다. 기존 웹사이트에서 브랜드 및 비주얼 디렉터로서의 정체성을 보여주었다면, 이번 페이지에서는 그 정체성을 전환하여 모델로서의 나를 보여주는 독립적인 포트폴리오 경험을 제공해야 한다.

기존 웹사이트의 디자인 시스템과 연결성을 유지하면서도, 모델 포트폴리오만의 독립적인 분위기와 시각적 인상을 형성해줘.


1. 페이지 진입 방식 및 전환 효과

• 기존 웹사이트의 푸터에 있는 as a model 버튼을 클릭하면 해당 모델 포트폴리오 페이지로 진입하도록 설정한다.
• 기존 웹사이트의 메인 화면과 모델 포트폴리오 페이지 사이에 극적인 시각적 전환 효과를 적용한다.
• 페이지 진입 시 기존 웹사이트의 메인 화면 레이아웃 구성은 그대로 유지한다.
• 반드시 기존 메인 화면의 레이아웃을 유지한 상태에서 다음 요소들을 흑백 반전으로 표현한다.
  1. 메인 화면의 배경색
  2. 헤더의 텍스트 컬러 및 헤더를 구성하는 모든 컬러
  3. 푸터의 텍스트 컬러 및 푸터를 구성하는 모든 컬러
• 기존 웹사이트가 흰색 계열의 배경과 검은색 계열의 텍스트를 사용한다면, 모델 포트폴리오 진입 시 검은색 계열의 배경과 흰색 계열의 텍스트로 반전한다.
• 단순한 페이지 이동이 아닌, 기존의 디렉터 포트폴리오에서 모델 포트폴리오로 전환되는 순간이 시각적으로 인식되도록 디자인한다.
• 전환은 과도한 애니메이션보다 색상의 반전과 레이아웃의 일관성을 활용하여 세련되게 구현한다.
• 모델 포트폴리오 페이지에서는 헤더 및 푸터의 레이아웃과 위치는 기존 웹사이트의 디자인 시스템을 유지한다.
• 모델 포트폴리오 페이지에서만 헤더 및 푸터의 구성은 기존 페이지의 헤더의 ‘VYN‘과 푸터의 ’AS A MODEL’을 제외한 모든 메뉴를 숨기고, 모델 포트폴리오 페이지에서만 푸터의 ’AS A MODEL’을 ’AS A DIRECTOR’로 텍스트를 변경하여 적용한다. 이때, ’AS A DIRECTOR’를 클릭 시, 기존의 디렉터 포트폴리오의 메인 페이지로 연결한다.
• 모델 포트폴리오 페이지에서만 헤더의 ‘VYN’을 클릭 시, 모델 포트폴리오의 메인 페이지로 연결한다.

2. 전체 디자인 방향

모델 포트폴리오의 메인 화면으로 디자인한다.

전체적인 방향은 다음과 같다.

• Minimal
• Editorial
• Contemporary
• Monochromatic
• Asymmetric
• Art-directed
• High-end fashion portfolio

불필요한 장식이나 그래픽 요소를 추가하지 않는다.

사진 자체가 가장 중요한 시각적 요소가 되어야 하며, 레이아웃은 사진의 개성과 분위기를 강조하는 역할을 해야 한다.

기존 웹사이트의 정돈된 미니멀리즘을 유지하면서도, 모델 포트폴리오에서는 보다 자유롭고 비정형적인 이미지 배치를 통해 새로운 인상을 만들어줘.

템플릿이나 일반적인 모델 에이전시 웹사이트처럼 보이지 않도록 한다.

3. 메인 이미지 레이아웃

첨부한 이미지를 참고하여 한 화면 안에 여러 장의 모델 사진이 흩어져 있는 비정형적인 이미지 레이아웃을 구성한다.

첨부 이미지는 이미지 배치 방식과 레이아웃만 참고한다. 

여백의 활용, 비정형 속 규칙적인 레이아웃의 특징을 적용한다.

첨부 이미지의 색감, 사진 스타일, 콘텐츠, 브랜드 요소를 그대로 복제하지 않는다.

레이아웃의 핵심 특징은 다음과 같다.

• 한 화면 안에 여러 장의 사진이 동시에 보이도록 구성한다.
• 이미지들이 규칙적인 그리드에 갇히지 않도록 한다.
• 사진마다 서로 다른 위치와 간격을 부여한다.
• 좌우 및 상하 공간을 적극적으로 활용한다.
• 넓은 여백을 유지한다.
• 이미지들이 화면 안에서 비정형적 정렬 규칙에 따라 자연스럽게 분산되어 보이도록 한다.
• 정렬과 비정렬이 적절히 혼합된 편집적인 구성을 만든다.
• 사진이 서로 겹치지 않는 기본 상태에서는 각 이미지의 개성과 형태가 명확하게 드러나야 한다.

이미지 크기

• 첨부 이미지의 개별 사진 크기보다 약 2배 큰 크기로 구성한다.
• 이미지가 너무 작아서 사진의 디테일이나 모델의 분위기를 파악하기 어려워지지 않도록 한다.
• 화면 크기에 따라 사진의 크기와 배치 간격을 유연하게 조정한다.
• 모든 이미지가 동일한 크기로 보이지 않도록 적절한 크기 변화를 적용한다.

메인 이미지

• 전체 사진 중 1장을 메인 이미지로 지정한다.
• 메인 이미지는 다른 사진보다 더 큰 크기로 배치한다.
• 메인 이미지는 페이지에 진입했을 때 모델의 인상을 가장 먼저 전달하는 역할을 해야 한다.
• 메인 이미지와 모델 이름이 페이지에서 가장 먼저 눈에 들어오도록 구성한다.
• 메인 이미지는 클릭 확대 기능을 적용하지 않고, 기본적으로 강조된 크기를 유지한다.

4. 사진 클릭 및 디테일뷰 기능

메인 이미지를 제외한 나머지 사진에 클릭 인터랙션을 적용한다.

일반적인 팝업, 모달, 라이트박스 방식은 사용하지 않는다.

클릭한 사진이 기존 레이아웃에서 배치되어 있던 바로 그 자리에서 확대되는 방식으로 구현한다.

구체적인 동작은 다음과 같다.

• 사진을 클릭하면 해당 이미지가 현재 배치된 위치를 기준으로 확대된다.
• 이미지의 원래 위치는 유지한다.
• 이미지가 화면 중앙으로 이동하지 않도록 한다.
• 이미지 확대 시 레이아웃 전체가 재배치되거나 다른 이미지들이 밀려나지 않도록 한다.
• 클릭한 사진만 확대되어 보이도록 한다.
• 확대된 사진이 주변의 다른 사진을 가리는 것은 허용한다.
• 확대된 사진은 다른 이미지보다 높은 레이어에 표시한다.
• 사진의 원래 비율을 유지한다.
• 확대 상태에서도 기존 웹사이트의 미니멀한 디자인 방향을 유지한다.
• 다시 클릭하거나 적절한 닫기 액션을 수행하면 원래 크기와 위치로 돌아온다.

이 기능은 단순히 이미지를 확대하는 것이 아니라, 비정형 레이아웃의 위치적 특성을 유지한 채 사진을 탐색하는 경험이어야 한다.

5. 페이지에 표시할 정보

모델 포트폴리오 페이지에는 아래 정보만 표시한다.

모델 이름

• 모델 이름을 가장 중요한 텍스트 요소로 설정한다.
• 메인 이미지와 함께 페이지 진입 시 가장 먼저 눈에 들어오도록 한다.
• 과도하게 크거나 장식적인 타이포그래피는 사용하지 않는다.
• 기존 웹사이트의 폰트 스타일과 차이점을 둔 폰트 스타일로 모델 포트폴리오에 적합한 인상을 만든다.

이메일

• 간단하고 미니멀한 연락처 정보로 표시한다.
• 불필요한 설명이나 아이콘을 추가하지 않는다.
• 이메일 주소를 클릭하면 메일 작성 화면으로 연결되도록 한다.
• 모델 이름의 타이포그래피에 서브텍스트로 어울리는 폰트 스타일로 설정한다.

Instagram

• Instagram 또는 실제 계정명을 텍스트 형태로 표시한다.
• 아이콘 대신 텍스트 중심으로 디자인한다.
• 클릭하면 Instagram 계정으로 이동하도록 설정한다.
• 모델 이름의 타이포그래피에 서브텍스트로 어울리는 폰트 스타일로 설정한다.

모델 이름, 이메일, Instagram 외에 불필요한 설명이나 소개 문구를 임의로 추가하지 않는다.

6. 반응형 디자인

• 데스크톱 화면을 기준으로 디자인한다.
• 태블릿과 모바일에서도 비정형 이미지 레이아웃의 특성을 유지한다.
• 화면 크기에 따라 이미지 크기와 배치를 자연스럽게 조정한다.
• 모바일에서는 사진이 지나치게 작아지거나 겹쳐서 콘텐츠를 확인하기 어려워지지 않도록 한다.
• 모바일에서도 메인 이미지와 모델 이름이 가장 먼저 인식되도록 한다.
• 사진 확대 인터랙션은 모바일에서도 적절하게 작동하도록 한다.

7. 구현 시 반드시 지켜야 할 사항

• 기존 웹사이트를 새로 디자인하거나 전체 구조를 변경하지 않는다.
• 기존 웹사이트의 프로젝트 페이지 및 다른 콘텐츠에 영향을 주지 않는다.
• as a model 버튼을 통해서만 모델 포트폴리오 페이지로 진입할 수 있도록 연결한다.
• 기존 웹사이트의 헤더와 푸터를 유지한다.
• 모델 포트폴리오 페이지는 독립적인 화면으로 작동하지만, 기존 웹사이트의 일부처럼 자연스럽게 연결되어야 한다.
• 기존 프로젝트 이미지와 콘텐츠를 임의로 수정하거나 삭제하지 않는다.
• 실제 사진이 준비되지 않은 경우 임시 이미지로 레이아웃을 구현하되, 나중에 사진을 쉽게 교체할 수 있도록 구성한다.
• 모든 클릭 인터랙션과 페이지 이동이 실제로 작동하도록 구현한다.


최종 디자인 목표

이 페이지는 일반적인 모델 프로필 페이지나 사진 갤러리가 아니다.

브랜드 및 비주얼 디렉터로서의 정체성을 보여주는 기존 웹사이트에서, 모델이라는 또 다른 정체성으로 자연스럽게 전환되는 하나의 시각적 경험이다.

흑백의 극적인 반전, 넓은 여백, 비정형 이미지 배치, 사진 자체의 존재감, 그리고 절제된 인터랙션을 통해 완성해줘.

사진을 나열하는 페이지가 아니라, 모델의 분위기와 이미지 자체가 하나의 비주얼 아카이브처럼 느껴지는 페이지를 만들어줘.

위의 모든 요구 사항을 반영하여 기존 웹사이트에 실제로 추가하고 구현해줘.
